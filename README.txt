# Cold Corner Billing App

Offline mobile web app for a Cold Corner shop.

Features:
- 100 item slots
- User-defined item name
- Buying and selling price
- Add new stock; current stock updates automatically
- Billing; sold quantity automatically subtracts from stock
- Out-of-stock / low-stock status
- Automatic sales and profit calculations
- Bill numbers and sales history
- Data saved on the phone/browser using local storage

## Use on Android
Open `index.html` in a browser. For a more app-like experience, use the browser's "Add to Home screen" option.

## Important
This version is an offline prototype. Data is stored locally on the device/browser. If browser data is cleared, the saved data can be lost. A future version can add backup/export, WhatsApp/thermal printing, PIN lock, and a proper Android APK/database.
